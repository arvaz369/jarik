# Skills Starter Kit — Готовые скиллы для Claude Code и Codex

> Справочник готовых скиллов и инструментов для быстрого старта. "Копируешь промпт, вставляешь в Claude Code или Codex — асистент сам скачает видео, пишет контент, анализирует конкурентов и собирает свои скиллы."

---

## Введение

**Готовые проверенные навыки, которые расширяют вашего ИИ-ассистента:**
- Скачивать и разбирать видео
- Писать контент
- Анализировать конкурентов
- Собирать свои скиллы

Все ссылки рабочие. Установка простая — скопировал промпт, вставил, готово.

---

## Как установить — 10 секунд

1. **Скопируй промпт** с любой карточки ниже
2. **Вставь его в чат Claude Code или Codex**
3. **Асистент сам скачает скилл и подключит** (со следующего сообщения от работает)

Для тех, кто дружит с терминалом — на карточках указана прямая команда.

## 0.3 Движки — фундамент, на котором всё работает

Это не скиллы, это **инструменты**, без которых видео-скиллы не работают.

### yt-dlp (179k★)

**Что это:** Главный инструмент скачивания видео и аудио с 1000+ сайтов (YouTube, Instagram, TikTok и т.д.)

**Установка:**
```bash
pip install -U yt-dlp
```

**Использование:**
```bash
yt-dlp https://youtube.com/watch?v=... -o "%(title)s.%(ext)s"
```

**Зачем:** Основа для video-downloader и других видео-скиллов. Без этого скиллы не работают.

**GitHub:** https://github.com/yt-dlp/yt-dlp

---

### OpenAI Whisper (105k★)

**Что это:** Превращает речь из видео и аудио в текст. Основа для разбора роликов и субтитров.

**Установка:**
```bash
pip install openai-whisper
```

**Использование:**
```bash
whisper video.mp4 --language ru
```

**Зачем:** Транскрибировать видео, получить текст из аудио, сделать субтитры

**GitHub:** https://github.com/openai/whisper

---

### FFmpeg (62k★)

**Что это:** Швейцарский нож для видео — конвертация, нарезка, извлечение звука, обработка

**Установка:**
```bash
# Windows (через Chocolatey)
choco install ffmpeg

# macOS
brew install ffmpeg

# Linux
sudo apt-get install ffmpeg
```

**Зачем:** Обрезать видео, вытаскивать звук, менять формат, вписывать субтитры

**GitHub:** https://github.com/FFmpeg/FFmpeg

## Практический сценарий: собрали контент-конвейер за 15 минут

**Решение:**

```
Установи три скилла в этом порядке:
```

**Результат:** Загружаешь ссылку на видео → скилл скачивает → разбирает → пишет контент

## Требования и совместимость

**Движки (требуют установки):**
- yt-dlp — Python 3.8+
- Whisper — Python 3.8+, PyTorch
- FFmpeg — система (Windows, macOS, Linux)

**Скиллы:**
- Работают в Claude Code и Codex
- Требуют активированного API (OpenAI для Whisper, если используется)

**Проверка установки:**
```bash
yt-dlp --version
whisper --version
ffmpeg -version
```

Если все три вернули версии — готовы к работе.

## Чистая правда про звёзды

Цифры (179k, 105k, 62k) — количество звёзд на GitHub. **Звёзды = популярность, а не гарантия**.

- yt-dlp (179k★) — пользуется половина интернета, очень надёжен
- Whisper (105k★) — OpenAI делает, всё работает
- FFmpeg (62k★) — стоит 20+ лет, устойчивый как железобетон

Готовые скиллы (69★) — молодые, но работают. Каждый скилл выше стоит на проверенном движке.

# 12 источников идей для контента (Справочник)

> Практический гайд по поиску идей для контента без творческого кризиса. 12 источников реального спроса, где аудитория уже спрашивает и обсуждает.

---

## Принцип

**"Хороший контент не придумывают с нуля. Его находят в реальном спросе."**

Схема: один вопрос → пять похожих → рубрика → продуктовая гипотеза.

---

## 12 источников

### 1️⃣ Вопросы клиентов

**Где:** Личные сообщения, комментарии, DM, письма

**Что ловить:** Возражения, сомнения, частые вопросы

**Как использовать:**
- Вопрос = заголовок статьи
- Возражение = аргумент против
- Сомнение = тема для разбора

**Пример:** Клиент спрашивает "Сколько стоит?" → статья "Полный гайд по ценообразованию"

---

### 2️⃣ Комментарии в нише

**Где:** Комментарии под постами конкурентов, блогерами, в сообществах

**Что ловить:** Частые вопросы, жалобы, ошибки понимания

**Как использовать:**
- Один вопрос в 5 комментариях = тема для поста
- Жалоба = боль, которую можно решить
- Ошибка = контент "как правильно"

**Пример:** 5 комментариев "Это долго?", "Сколько времени?" → пост "За какое время результат"

---

### 3️⃣ YouTube

**Что ловить:** Популярные видео, заголовки, комментарии, плейлисты

**Как использовать:**
- Топ-видео в нише = тем для контента
- Заголовок с цифрой = готовый формат
- Комментарии под видео = уточняющие вопросы

**Пример:** Видео "5 способов заработать" → адаптируешь для своей ниши "5 способов для вашей задачи"

**Инструменты:** YouTube Analytics, Видео-рейтинги по просмотрам

---

### 4️⃣ Telegram-чаты

**Где:** Тематические чаты, чаты вашей ниши, комьюнити

**Что ловить:** Живые боли, обсуждения, вопросы, ошибки

**Как использовать:**
- Тема дня в чате = горячая тема
- Вопрос, который задает 3+ человека = контент
- Дискуссия = возможность для гайда "как разрешить спор"

**Пример:** В чате обсуждают "как выбрать платформу" → вы выпускаете сравнение

---

### 5️⃣ Perplexity AI

**Что это:** Поисковая система с AI, показывает актуальные вопросы

**Что ловить:** Растущие запросы, тренды, новые вопросы

**Как использовать:**
- Актуальные вопросы = готовые заголовки
- Тренды = возможность быть первым
- Новые темы = ниша с низкой конкуренцией

**Пример:** Perplexity показывает "как использовать X в 2026" → вы пишете гайд первыми

---

### 6️⃣ Google Trends

**Что это:** Статистика поисковых запросов от Google

**Что ловить:** Растущие запросы, сезонные темы, геолокация

**Как использовать:**
- Растущий запрос (линия вверх) = писать контент сейчас
- Сезонные темы = планировать контент за месяц
- По регионам = адаптировать контент

**Пример:** Видно что запросы "как..." растут → пишете гайд пока спрос растет

---

### 7️⃣ Metricool

**Что это:** Аналитика социальных сетей с фильтром по вовлечённости

**Как это работает:** Подключается как источник данных / MCP для Claude

**Что ловить:** Посты с высокой вовлечённостью, работающие форматы

**Как использовать:**
- Топ-посты вашего канала = рубрики, которые работают
- Форматы других = адаптировать под себя
- Время постинга = когда публиковать

**Пример:** Видно что видео работает лучше, чем текст → переходите на видео

---

### 8️⃣ ChatGPT / Claude

**Что это:** AI для раскладки тем и адаптации контента

**Как использовать:**
- Промпт: "раскладать тему на подтемы" → структура поста
- "Переписать для новичков" → адаптация уровня сложности
- "5 углов для статьи" → разные углы один тему

**Пример:** 
```
Промпт: "Даю тему 'как выбрать инструмент'. 
Раскладай на 5 подтем и 3 угла для каждой"
Результат: готовая структура на месяц контента
```

---

### 9️⃣ Отзывы и форумы

**Где:** Otzovik.com, Яндекс.Карты, маркетплейсы (Озон, Яндекс.Маркет)

**Что ловить:** Боли, возражения, непонимание, ошибки использования

**Как использовать:**
- Возражение в отзыве = возможность контента "как справиться"
- Ошибка = гайд "как правильно"
- Боль = решение в виде контента

**Пример:** Отзыв "Не понял как настроить" → пост "Пошаговая настройка за 5 минут"

---

### 🔟 Авито

**Что это:** Маркетплейс с живыми вопросами покупателей

**Что ловить:** Вопросы под объявлениями, спрос, сомнения

**Как использовать:**
- Вопрос = боль клиента
- Спрос = популярность темы
- Возражение = аргумент против (нужно опровергнуть)

**Пример:** Под объявлением 20 вопросов "сколько стоит доставка" → пост про доставку

---

### 1️⃣1️⃣ Поисковые подсказки

**Где:** Яндекс, Google (при вводе в строку поиска)

**Что ловить:** Автодополнение (что ищут люди), вопросы ("как...", "почему...")

**Как использовать:**
- Подсказка = готовый заголовок
- "Как..." = структура для гайда
- "Почему..." = тема для разбора

**Пример:** Вводишь "инструмент", видишь:
- "инструмент как выбрать" → пост про выбор
- "инструмент цена" → пост про ценообразование

---

### 1️⃣2️⃣ Ваш лучший контент

**Где:** Ваши статьи, посты, видео, которые работают

**Что ловить:** Темы, форматы, стиль, которые резонируют

**Как использовать:**
- Топ-контент = развивать дальше (продолжение, глубже, обновить)
- Формат = применить к новым темам
- Стиль = заимствовать тон

**Пример:** Пост "5 советов" с 1000 просмотров → 
- Продолжение: "10 продвинутых советов"
- Новая тема: "5 советов для X"
- Видео версия того же

---

## Схема использования источников

```
1. Одиночный вопрос
   ↓
2. Поиск 5 похожих вопросов (через разные источники)
   ↓
3. Вывод: это рубрика (тема, которая интересует)
   ↓
4. Продуктовая гипотеза:
   - Гайд (как решить)
   - Инструмент (упростить решение)
   - Сервис (делать это за них)
```

## Как монетизировать источники

| Источник | Монетизация |
|----------|------------|
| **Вопросы клиентов** | Услуга / консультация |
| **Комментарии** | Рубрика / серия постов |
| **YouTube** | Адаптация + собственная версия |
| **Telegram-чаты** | Групповое решение / продукт |
| **Perplexity** | Первое решение тренда |
| **Google Trends** | Тайминг + SEO |
| **Metricool** | Форматы + рубрики |
| **ChatGPT/Claude** | Быстрая генерация контента |
| **Отзывы** | Возражение-опровержение (FAQ) |
| **Авито** | Спрос на рынке |
| **Подсказки** | SEO + заголовки |
| **Ваш контент** | Расширение лучшего |

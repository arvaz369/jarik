# Фабрика контент-агентов: Каталог 34 Open-Source проектов

> Справочник готовых компонентов для автоматизации контента — от поиска тем до автопостинга. 9 категорий, практическая методология выбора и адаптации через Claude Code.

---

## Философия

**"Не устанавливайте всё сразу."**

Стратегия: выберите 1-2 проекта под вашу задачу → изучите архитектуру → адаптируйте через Claude Code под ваши нужды.

Это не готовая система, это конструктор компонентов.

## 9 Категорий

### 1️⃣ Поиск и Research

**Цель:** Автоматизировать сбор данных, анализ трендов, генерацию аналитики

| Проект | Что делает | Технология | Сложность |
|--------|-----------|-----------|-----------|
| **firecrawl** | Веб-скрейпинг и структурирование данных для бриефов | Python/Node.js | 🟡 Средняя |
| **Agent-Reach** | Мониторит тренды в Twitter, Reddit, YouTube в реальном времени | Python | 🟡 Средняя |
| **gpt-researcher** | Генерирует развёрнутые отчёты с источниками и аналитикой | Python + Claude API | 🟢 Простая |

**Когда использовать:** Клиент хочет автоматический мониторинг трендов, конкурентов, источников идей.

## Методология выбора и адаптации

### Шаг 1: Определи задачу

Спроси клиента: что нужно автоматизировать?
- Поиск идей? → категория 1 (Research)
- Написание постов? → категория 2 (Текст)
- Видео? → категория 3 (Видео)
- И т.д.

### Шаг 2: Выбери 1-2 проекта

Не берись за все сразу. Например:
- Для видео-блогера: MoneyPrinterTurbo + Whisper
- Для копирайтера: ALwrity + social-media-agent
- Для мультиканального: postiz-app + n8n

### Шаг 3: Изучи исходный код

Откройте на GitHub, посмотрите:
- Архитектура (какие компоненты)
- Зависимости (Python, Node.js, что ещё)
- Примеры использования (в README)

### Шаг 4: Адаптируй через Claude Code

Покажи проект Claude Code:
```
Вот код проекта [firecrawl]. 
Как адаптировать это для моей задачи?
Нужно добавить X, убрать Y, изменить Z.
```

Claude разберётся в архитектуре и подскажет, как модифицировать.

### Шаг 5: Интегрируй в свою систему

Встрой компонент в ваш контент-конвейер:
- Как вход для следующего этапа
- Как часть агента
- Как отдельный микросервис

## Практический пример: Контент-конвейер для клиента

```
Задача: "Автоматизировать полный цикл контента"

Выбор проектов:
1. gpt-researcher     → исследование + вывод идей
2. ALwrity            → написание текста
3. ComfyUI            → генерация обложки
4. OpenVoice          → озвучка
5. postiz-app         → публикация во все сети

Процесс:
1. gpt-researcher находит тренд
2. ALwrity пишет пост (текст)
3. ComfyUI генерирует обложку
4. OpenVoice озвучивает пост (аудио)
5. postiz-app публикует везде

Результат: полный контент в один клик
```

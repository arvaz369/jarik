# Экономия токенов в Claude Code — памятка

> Источник: https://claude.com/blog/maximizing-the-value-of-your-claude-code-sessions
> Дата добавления: 2026-08-17

Цель не «тратить меньше токенов», а «тратить их только на то, что реально просил».

---

## В начале сессии

1. Зайди в Claude Code
2. Выбери модель (`/model`) и уровень effort (`/effort`) — один раз, под задачу
3. Не переключай модель/effort посреди сессии — это сбрасывает кеш и удорожает следующие ходы

## Во время работы

4. Нужен файл — упомяни его через `@файл`, не проси «прочитай файл по пути X»
5. Команда даёт много вывода (тесты, логи) — знай, что весь этот вывод останется в разговоре и будет перечитываться на каждом следующем шаге
6. Хочешь проверить, что реально загружено в контекст — набери `/context`

## Перед перерывом или сменой задачи

7. Задача завершена, начинается новая — набери `/clear`
8. Сессия важная и понадобится позже — сначала `/rename`, потом `/clear`
9. Уходишь надолго (кеш живёт ~час) — набери `/compact`, чтобы не платить за перечитывание истории заново
10. Если нужно откатить последние шаги — `/rewind` (бесплатно, историю не переписывает)

---

## Короткая таблица команд

| Команда | Когда использовать |
|---|---|
| `/model`, `/effort` | В начале сессии, один раз |
| `@файл` | Вместо просьбы «прочитай файл» |
| `/context` | Проверить, что загружено |
| `/clear` | Новая задача |
| `/compact` | Перед перерывом |
| `/rename` | Перед `/clear`, если сессия ещё пригодится |
| `/rewind` | Откатить последние шаги без затрат |

# Obsidian Mind — шаблон постоянной памяти для AI-агентов

> Инструмент для клиентов, которые хотят локальное решение с полным контролем над памятью. Альтернатива облачным системам памяти.

---

## Что это

**Obsidian Mind** — это хранилище (vault) Obsidian, которое превращает Obsidian в операционную систему памяти для AI-агентов (Claude Code, Codex, Gemini). Система позволяет агентам запоминать контекст между сеансами.

Когда клиент работает с агентом в Claude Code:
- Агент видит его цели, проекты, недавние решения
- Не требует облака или внешних серверов
- Память хранится локально в Git-репозитории
- Полностью под контролем клиента

---

## Требования

```
• Obsidian 1.12+ (для CLI)
• Claude Code / Codex CLI / Gemini CLI
• Node 22+ LTS (для TypeScript-хуков)
• Git (для истории)
• QMD (опционально, для семантического поиска)
```

---

## Как установить для клиента

### Вариант 1: ShardMind (проще)
```bash
npm install -g shardmind
mkdir my-agent-vault && cd my-agent-vault
shardmind install github:breferrari/obsidian-mind
```
Мастер запросит имя, цель, автоматически инициализирует Git и `North Star.md`.

### Вариант 2: Клонировать как шаблон
```bash
git clone https://github.com/breferrari/obsidian-mind.git my-agent-vault
# Заполнить brain/North Star.md вручную
```

### QMD для семантического поиска (рекомендуется)
```bash
npm install -g @tobilu/qmd
node --experimental-strip-types scripts/qmd-bootstrap.ts
```

## Архитектура памяти

### 5 хуков автоматизации

| Хук | Момент | Что происходит |
|-----|--------|---------|
| **SessionStart** | Запуск сеанса | Переиндексация, инъекция North Star, активных проектов, недавних решений (~2K токенов) |
| **UserPromptSubmit** | Каждое сообщение | Классификация контента (решение / инцидент / победа / заметка) |
| **PostToolUse** | После записи .md | Валидация frontmatter, проверка вики-ссылок |
| **PreCompact** | Перед компактацией | Резервная копия транскрипта |
| **Stop** | Конец сеанса | Проверка целостности хранилища |

### Структура папок

```
Home.md                    Входная точка (встроенные Base-представления)
CLAUDE.md                  Инструкции для агента
AGENTS.md                  Инструкции для других IDE

brain/
  ├─ North Star.md         Цели и приоритеты (переиндексируется каждый сеанс)
  ├─ Memories.md           Индекс тем памяти
  ├─ Key Decisions.md      Архитектурные решения
  ├─ Patterns.md           Найденные закономерности
  └─ Skills.md             Умения и компетенции

work/
  ├─ active/               Текущие проекты
  ├─ archive/YYYY/         Завершённые проекты
  ├─ incidents/            Инциденты и их разрешение
  └─ 1-1/                  Встречи один-на-один

org/
  ├─ people/               По одной заметке на человека
  └─ teams/                Команды и их роли

perf/
  ├─ Brag Doc.md           Логирование побед
  ├─ competencies/         Компетенции
  └─ evidence/             Доказательства для ревью

templates/                 Шаблоны с YAML frontmatter
reference/                 Документация, архитектура
thinking/                  Черновики (удалять после проверки)

.claude/
  ├─ commands/             18 встроенных команд
  ├─ agents/               9 специализированных субагентов
  └─ scripts/              Хук-скрипты
```

## 18 команд

Основные команды для повседневной работы:

**Утро/День:**
- `/om-standup` — обзор дня (North Star, активные проекты, приоритеты)
- `/om-dump` — свободный захват контента в заметки
- `/om-wrap-up` — обзор сеанса (проверка, индексирование, ссылки)

**Встречи:**
- `/om-capture-1on1` — структурированная запись встречи 1:1
- `/om-prep-1on1` — подготовка к встречам
- `/om-meeting` — подготовка к встречам по теме
- `/om-incident-capture` — захват инцидента

**Интеграции:**
- `/om-slack-scan` — скан каналов и ДМ из Slack
- `/om-peer-scan` — анализ PR коллеги

**Обслуживание:**
- `/om-tidy` — автоматическое обслуживание
- `/om-vault-audit` — проверка индексов, ссылок, сирот
- `/om-vault-upgrade` — миграция из старого хранилища
- `/om-humanize` — редактирование текста под стиль

**Производительность:**
- `/om-weekly` — синтез недели
- `/om-review-brief` — бриф для ревью (менеджер)
- `/om-self-review` — самооценка
- `/om-review-peer` — рецензия на коллегу

## 9 субагентов

Каждый запускается в изолированном контексте:

| Агент | Функция |
|-------|---------|
| **brag-spotter** | Находит упущенные достижения и победы |
| **context-loader** | Загружает контекст о человеке или проекте |
| **cross-linker** | Ищет недостающие вики-ссылки между заметками |
| **people-profiler** | Создаёт заметки о людях из Slack-профилей |
| **review-prep** | Агрегирует доказательства производительности |
| **slack-archaeologist** | Полная реконструкция истории Slack |
| **vault-librarian** | Глубокое обслуживание хранилища |
| **review-fact-checker** | Проверяет ревью против источников |
| **vault-migrator** | Миграция из других хранилищ |

## Ограничения

⚠️ **TypeScript-хуки требуют Node 22+** — флаг `--experimental-strip-types`  
⚠️ **QMD опционален** — первый запуск загружает ~328MB модель  
⚠️ **ShardMind не обязателен** — хранилище работает и без него  
⚠️ **Требует Obsidian** — ещё один инструмент для клиента  
⚠️ **Миграция** — для старых vaults требуется переклассификация

## Когда предлагать клиентам

**Предложить Obsidian Mind:**
- Клиент предпочитает локальное решение, не облако
- Клиент уже использует Obsidian
- Клиент хочет полный контроль над памятью и данными
- Клиент готов потратить 2-3 часа на настройку
- Клиент хочет семантический поиск по своей памяти

**Не предлагать:**
- Клиент хочет ready-to-use solution без настройки
- Клиент боится командной строки и Node.js
- Клиент не хочет ещё один инструмент (уже есть CloudFlare, Notion и т.д.)
- Клиент предпочитает облачное хранение для синхронизации

## Процесс внедрения для клиента

1. **Оценка** — выяснить, что клиент уже использует (Obsidian? Git?)
2. **Установка** — ShardMind или клонирование + ручная настройка North Star.md
3. **Обучение** — показать 3-5 основных команд (`/om-standup`, `/om-dump`, `/om-wrap-up`)
4. **Интеграция** — подключить QMD (опционально), настроить Slack-скан (опционально)
5. **Поддержка** — помощь с `/om-vault-audit`, `/om-tidy`

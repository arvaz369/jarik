# humanizer-ru — Очистка русского текста от AI-штампов

> Специализированный скилл для Claude Code, который берёт русский текст и убирает всё "по чему его палят" — канцеляризм, типичные ChatGPT штампы и копипаста артефакты.

---

## Введение

Когда Claude пишет текст, он часто использует:
- Канцеляризм: "осуществляем проведение"
- ChatGPT штампы: "давайте разберемся", "как мы видим"
- Копипаста артефакты: utm-параметры, [cite: 8], служебные метки
- Излишнюю формальность: "Позволите предложить"

**humanizer-ru** находит и убирает это автоматически, сохраняя факты и смысл.

---

## Как работает

**Три этапа обработки:**

### 1️⃣ Сканирование

Поиск проблем по **37 паттернам**:
- Водяные слова: "осуществлять", "проведение", "организовать"
- ChatGPT маркеры: "давайте разберемся", "как мы видим", "позвольте предложить"
- Служебные метки: `[cite: 8]`, `utm_source=chatgpt.com`, `[assistant]`
- Стилистические проблемы: перечисления, клише, формальность

### 2️⃣ Редактура

Исправление только найденных проблем:
- Не переписывает весь текст
- Сохраняет факты и цифры нетронутыми
- Не деградирует качественный текст
- Минимальные правки

### 3️⃣ Проверка

Финальная валидация через Python-скрипт:
- Проверка целостности текста
- Проверка что смысл не изменился
- Валидация синтаксиса

## Основные функции

### Очистка текста

**Режим "редактура"** — убрать AI-штампы и воду

```
Входной текст:
"Мы осуществляем проведение мероприятий. Позволите предложить несколько идей."

Выходной текст:
"Мы работаем эффективнее. Вот несколько идей."
```

### Детекция AI

**Режим "проверка"** — найти AI-маркеры без редактирования

Возвращает:
- Список улик с цитатами
- Вердикт: "это писала нейросеть"
- Уровень уверенности

### Распознавание артефактов

Ловит служебные метки копипаста:
- `utm_source=chatgpt.com`
- `[cite: 8]`, `[1]`, `[2]`
- HTML-комментарии: `<!-- assistant -->`
- JSON-служебные метки

## 37 Паттернов сканирования

### Категория 1: Водяные слова (10 паттернов)

| Паттерн | Замена | Пример |
|---------|--------|--------|
| осуществлять | делать, работать | "осуществляем проведение" → "проводим" |
| проведение | - | удалить |
| организовать | сделать, запустить | "организуем встречу" → "встреча" |
| позволить | - | "позвольте предложить" → "вот идея" |
| предложить | сказать, показать | иногда убирать |
| предоставить | дать | "предоставляем информацию" → "вот информация" |
| обеспечить | дать, гарантировать | убрать если излишне |
| произвести | сделать | убрать канцеляризм |
| обратить внимание | заметить | "обратите внимание" → "важно" |
| принять решение | решить | убрать лишние слова |

### Категория 2: ChatGPT маркеры (12 паттернов)

| Маркер | Проблема | Решение |
|--------|----------|---------|
| "давайте разберемся" | Клише ChatGPT | "вот решение:" |
| "как мы видим" | Типичный ввод | убрать |
| "важно отметить" | Формальный вводитель | убрать или переформулировать |
| "следует упомянуть" | Лишняя формальность | убрать |
| "стоит сказать" | Вводитель | убрать если не критично |
| "можно утверждать" | Неуверенность | "это" вместо "можно утверждать" |
| "в целом" | Начальный штамп | убрать в начале предложения |
| "иными словами" | Повторение | часто можно убрать |
| "в наше время" | Шаблонное введение | убрать или обновить |
| "на сегодняшний день" | Устаревший штамп | убрать |
| "как известно" | Кондescending | убрать |
| "по мнению эксперта" | Неопределенность | убрать если не назван эксперт |

### Категория 3: Служебные метки (8 паттернов)

| Метка | Действие |
|-------|----------|
| `[cite: X]` | Удалить |
| `[1]`, `[2]` | Удалить если не нужны ссылки |
| `utm_source=` | Удалить параметр |
| `<!-- assistant -->` | Удалить HTML-комментарий |
| `{cite}` | Удалить JSON-метку |
| `[ASSISTANT]` | Удалить служебный маркер |
| `` (двойные пробелы) | Привести к одному пробелу |
| `\n\n\n` (тройные переносы) | Привести к двойным |

### Категория 4: Стилистические проблемы (7 паттернов)

| Проблема | Решение |
|----------|---------|
| Перечисления через точку с запятой (формальный стиль) | Переписать как маркированный список или объединить |
| Длинные предложения > 25 слов | Разбить на 2-3 |
| "Еще один момент..." повторение | Убрать избыточные переходы |
| Пассивный залог (была проведена оценка) | Активный (оценили) |
| Многосложные слова без необходимости | Простые эквиваленты |
| Повторение одного слова > 3 раз | Синонимы или структура |
| Лишние вводные обороты | Убрать если не критичны |

## Практические примеры

### Пример 1: Очистка маркетинг-текста

```
Позвольте предложить решение, которое поможет вам осуществить проведение
```

```
Вот решение для эффективного анализа данных. Это критично.
```

**Входной текст:**

```
Согласно исследованию [cite: 5], результаты показывают, что в наше время
```

**Выходной текст:**
```
Исследования показывают, что люди предпочитают быстрые решения.
```

### Пример 3: Пассивный залог

**Входной текст:**
```

```

**Выходной текст:**
```
Оценили и выявили несколько проблем.
```

## Когда использовать

✅ **Используй humanizer-ru:**
- Текст написал Claude (или другая нейросеть)
- Нужно убрать AI-маркеры и штампы
- Нужна проверка на AI-генерацию
- Русский контент (основной фокус)

❌ **Не используй:**
- Текст написан человеком (может испортить)
- Английский текст (фокус на русском)
- Юридические документы (осторожнее с изменениями)

## Интеграция в workflow

### Вариант 1: После генерации контента

```
1. Claude генерирует текст (пост, статью, письмо)
2. /humanize-text очищает
3. Ты проверяешь (факты, логика)
4. Публикуешь
```

### Вариант 2: Перед отправкой

```
1. Написал письмо клиенту
2. /check-ai-markers проверяет нет ли AI-маркеров
3. Отправляешь
```

### Вариант 3: Массовая обработка

```
1. Имеешь файл с текстами
2. /humanize-doc обрабатывает
3. Сохраняет результат
4. Ты проверяешь
```

## Ограничения

⚠️ **Помни:**
- Не гарантирует 100% удаление AI-маркеров (для полной скрытности нужна ручная проверка)
- Может не поймать новые штампы, которые появляются
- Лучше работает на длинных текстах (10+ предложений)
- Фокус на русском языке

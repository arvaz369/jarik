# Справочник скиллов: какие установить для какого типа агента

> Руководство для выбора скиллов при разработке новых агентов. Используй при внедрении для SMB, разработке демо-кейсов, и расширении функциональности агента.

---

## Быстрая справка: 4 типа агентов

| Тип агента | Скиллы | Время настройки | Рекомендуется для |
|-----------|--------|-----------------|-------------------|
| **MVP (прототип)** | 1–2 базовых | 1 час | Быстрая демонстрация |
| **SMB (малый бизнес)** | 4 базовых + гstack | 4–8 часов | Компании 5–100 человек |
| **Mid-Market (средний бизнес)** | 4 базовых + гstack + расширения | 1–2 дня | Компании 100–500 человек |
| **Enterprise (крупный бизнес)** | Все + кастомные | 2–4 недели | Компании 500+ человек |

---

## 1️⃣ Базовые скиллы (обязательные)

Эти 4 скилла нужны **каждому агенту**:

### ❓ discovery-interview (Интервьюер)
**Функция:** преобразует идеи в техническое задание через 7-фазное интервью.

**Когда использовать:**
- На старте проекта (сбор требований)
- Когда клиент не знает, что ему нужно

**Результат:** готовое ТЗ вместо размытых идей

**Пример:** клиент говорит "нужен сайт". Интервьюер спрашивает 7 вопросов, получается полное ТЗ.

---

### ✍️ content-creator (Писатель)
**Функция:** создаёт контент (посты, письма, статьи, описания) в авторском стиле.

**Когда использовать:**
- Создание маркетинг-материалов
- Написание документации
- Подготовка текстов для соцсетей

**Результат:** качественный контент в едином стиле

**Пример:** "Напиши пост о новом фича для LinkedIn в стиле нашего блога" → готовый пост

---

### 💻 fullstack-developer (Разработчик)
**Функция:** разработка сайтов, форм, ботов, скриптов автоматизации.

**Когда использовать:**
- Создание прототипов
- Разработка backend/frontend
- Автоматизация задач

**Результат:** рабочий код, готовый к деплою

**Пример:** "Сделай форму для сбора заявок с отправкой в CRM" → готовая форма + webhook

---

### 🎨 frontend-design (Дизайнер)
**Функция:** создание красивых интерфейсов, лендингов, дизайн-систем.

**Когда использовать:**
- Дизайн UI/UX
- Создание лендингов
- Подготовка макетов

**Результат:** production-ready HTML/CSS с хорошим дизайном

**Пример:** "Сделай красивый лендинг для нашего сервиса" → готовый лендинг

## 2️⃣ Расширение: gstack (для профессионального качества)

**gstack** — комплекс из 50+ команд. Не дублирует базовые скиллы, добавляет глубину.

### Категория: Планирование

| Команда | Функция | Когда использовать |
|---------|---------|---|
| `/spec` | Преобразование идей в точные спецификации (5 этапов) | Когда ТЗ нужно детализировать |
| `/autoplan` | Автоматический запуск всех проверок качества | Перед доставкой кода |
| `/plan-eng-review` | Интерактивная проверка плана инженером | Техническая валидация |
| `/plan-design-review` | Проверка плана дизайнером | Дизайн-консистентность |

**Когда добавить:** когда клиент требует качество, а не скорость.

---

### Категория: Разработка и QA

| Команда | Функция | Когда использовать |
|---------|---------|---|
| `/ship` | Полный workflow доставки (слияние, тесты, bump версии, PR) | Финальная доставка кода |
| `/review` | Проверка PR перед интеграцией | Code review без людей |
| `/qa` | Тестирование веб-приложений и исправление ошибок | Перед продакшеном |
| `/benchmark` | Тестирование производительности | Оптимизация скорости |
| `/investigate` | Систематическая отладка с анализом корневых причин | Сложные баги |

**Когда добавить:** когда нужна гарантия качества (не MVP).

---

### Категория: Дизайн (продвинутый)

| Команда | Функция | Когда использовать |
|---------|---------|---|
| `/design-consultation` | Полная разработка дизайн-системы | Крупный проект |
| `/design-html` | Генерация production HTML/CSS | Быстрое создание интерфейсов |
| `/design-review` | Проверка визуальной согласованности | Контроль качества дизайна |
| `/design-shotgun` | Создание и сравнение вариантов дизайна | Выбор лучшего варианта |

**Когда добавить:** когда дизайн — критичный фактор.

---

### Категория: Утилиты

| Команда | Функция | Когда использовать |
|---------|---------|---|
| `/browse` | Быстрый headless browser для тестирования (50+ операций) | Автоматизированное тестирование |
| `/scrape` | Извлечение данных со страниц | Сбор информации, дата-инженеринг |
| `/diagram` | Создание диаграмм из текста | Документирование архитектуры |
| `/document-generate` | Генерация документации | Автоматическое документирование кода |
| `/make-pdf` | Конвертация markdown в PDF | Экспорт отчётов, спецификаций |

**Когда добавить:** когда нужна автоматизация рутины.

## 3️⃣ Дополнительные расширения

### ✨ remotion-video-skill (Видеомейкер)
**Функция:** создание видео с Remotion (анимированных демонстраций).

**Когда использовать:**
- Создание демо-видео для клиентов
- Маркетинг-видео
- Демонстрация функциональности

**Стоимость:** немного увеличивает время на 30-60 минут per video

**Рекомендуется для:** демо-кейсов и маркетинга

---

### 🧠 prompt-master (Оптимизатор промптов)
**Функция:** оптимизация промптов для AI инструментов (улучшение качества).

**Когда использовать:**
- Когда качество ответов агента недостаточно
- Тонкая настройка поведения
- Оптимизация под специфические требования

**Экономия:** может снизить затраты на токены на 20–40%

**Рекомендуется для:** всех агентов (как расширение)

---

### ⚡ context-engineering (Оптимизатор контекста)
**Функция:** уменьшение токенов без потери качества (экономия API).

**Когда использовать:**
- Когда затраты на API слишком высоки
- Для клиентов с большим объёмом запросов
- Оптимизация памяти агента

**Экономия:** может снизить затраты на 30–50%

**Рекомендуется для:** SMB+ агентов (важна экономия)

---

### 🎨 taste-skill (Эстетика)
**Функция:** улучшение эстетики дизайна (избегает AI-generated look).

**Когда использовать:**
- Когда дизайн должен выглядеть профессионально
- Избежание стандартного AI-дизайна
- Высокие требования к UI/UX

**Результат:** дизайн выглядит как сделано человеком

**Рекомендуется для:** демо, лендингов, критичных проектов

## 4️⃣ Предустановки для разных типов агентов

Используй эти наборы как шаблон при разработке нового агента:

### 🚀 MVP (минимальный прототип) — 1–2 часа

```
✅ discovery-interview  (сбор требований)
✅ fullstack-developer  (разработка)
```

**Используй когда:** быстрая демонстрация идеи клиенту.

**Результат:** работающий прототип, готовый к обсуждению.

---

### 🏢 SMB-агент (малый бизнес) — 4–8 часов

```
✅ discovery-interview    (сбор требований)
✅ content-creator        (контент)
✅ fullstack-developer    (разработка)
✅ frontend-design        (дизайн)
✅ gstack (/spec, /qa, /ship, /review)  (качество)
✅ context-engineering    (экономия API)
```

**Используй для:** компаний 5–100 человек с ограниченным бюджетом.

**Стоимость:** ~$2000–5000 на внедрение.

**Результат:** полнофункциональный агент, экономный по API.

---

### 📈 Mid-Market (средний бизнес) — 1–2 дня

```
✅ discovery-interview
✅ content-creator
✅ fullstack-developer
✅ frontend-design
✅ gstack (все команды)         (полный арсенал)
✅ prompt-master                (качество)
✅ context-engineering          (экономия)
✅ taste-skill                  (эстетика)
✅ remotion-video-skill         (демо)
```

**Используй для:** компаний 100–500 человек, требователь к качеству.

**Стоимость:** ~$5000–15000 на внедрение.

**Результат:** премиум-агент с полным набором функций.

---

### 🏛️ Enterprise (крупный бизнес) — 2–4 недели

```
✅ Все базовые скиллы
✅ gstack (полный набор)
✅ Все расширения
✅ Кастомные скиллы (в зависимости от задач)
✅ Интеграция с внутренними системами
```

**Используй для:** крупных организаций, специализированные требования.

**Стоимость:** $15000+ на внедрение.

**Результат:** встроенный нейросотрудник под конкретные задачи.

## 5️⃣ Матрица: функция ↔ скилл

Когда клиент говорит "нам нужно", используй эту таблицу:

| Клиент говорит | Рекомендуемые скиллы |
|---|---|
| "Нужен сайт" | fullstack-developer + frontend-design + taste-skill |
| "Автоматизируй сбор заявок" | fullstack-developer + gstack /browse |
| "Генерируй контент для соцсетей" | content-creator + remotion-video-skill |
| "Проверяй код перед запуском" | gstack (/qa, /review, /ship) |
| "Нужна оптимизация затрат на API" | context-engineering + prompt-master |
| "Разработай дизайн-систему" | frontend-design + gstack /design-consultation |
| "Документируй нашу архитектуру" | gstack /diagram, /document-generate |
| "Создай демо для инвесторов" | fullstack-developer + frontend-design + remotion-video-skill |

## 6️⃣ Что НЕ устанавливать

### ❌ marketingskills
**Почему:** для маркетологов, не для архитектора агентов. Отвлекает от основной цели.

**Исключение:** если специально разрабатываешь маркетинг-агента.

---

## 7️⃣ Чек-лист при выборе скиллов для нового клиента

```
1. ✓ Определить размер компании (SMB / Mid-Market / Enterprise)
2. ✓ Выбрать базовые 4 скилла (всегда)
3. ✓ Выбрать из gstack нужные команды (планирование, разработка, дизайн, утилиты)
4. ✓ Добавить расширения (context-engineering, prompt-master)
5. ✓ Если нужна эстетика → taste-skill
6. ✓ Если нужны видео → remotion-video-skill
7. ✓ Проверить бюджет (сметасовать на внедрение)
8. ✓ Показать демо на похожем проекте
```

---

## Заключение

**Никогда не устанавливайте все скиллы сразу** — это шум и отвлечение.

**Правило:** выбирайте ровно столько, сколько нужно клиенту, **плюс один** для будущего расширения.

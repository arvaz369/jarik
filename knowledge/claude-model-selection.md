# Карта выбора модели Claude — Шпаргалка

> Практический справочник для выбора модели, effort уровня и управления затратами в Claude Code. "Когда Sonnet 5, когда Opus 4.8, когда Haiku. Настройка effort и команды, чтобы не переплачивать за токены."

---

## 3 модели Claude

### 🔴🔴 Sonnet 5 — ДЕФОЛТ

**Для:** Повседневная разработка, агентные задачи, объём

| Параметр | Значение |
|----------|----------|
| **Когда использовать** | Большинство задач (80% работы) |
| **Сильные стороны** | Баланс скорость-качество, экономичность |
| **Слабые стороны** | Меньше точности чем Opus |
| **Цена** | $3 / $15 (вход / выход за 1M токенов) |
| **Вводная скидка** | $2 / $10 до 31 августа |
| **Context window** | 1M токенов (самый большой) |

**Используй Sonnet когда:**
- ✅ Повседневная разработка
- ✅ Код (если не критичная точность)
- ✅ Большой контекст нужен (1M токенов)
- ✅ Хочешь экономить
- ✅ Задача стандартная, не на грани

---

### 🟢🔴 Opus 4.8 — ТОЧНОСТЬ

**Для:** Сложный рефакторинг, глубокая отладка, высокая цена ошибки

| Параметр | Значение |
|----------|----------|
| **Когда использовать** | Только где нужна максимальная точность |
| **Сильные стороны** | Сложный рефакторинг, глубокая отладка, высокая цена ошибки |
| **Слабые стороны** | Дорогая (3x дороже Sonnet), медленнее |
| **Цена** | $5 / $25 (вход / выход за 1M токенов) |
| **Флагман** | Лучший при неограниченном бюджете |
| **Context window** | 1M токенов |

**Используй Opus когда:**
- ✅ Критичная архитектура (ошибка = потеря дней)
- ✅ Сложный рефакторинг (много файлов, зависимостей)
- ✅ Глубокая отладка (найти корень проблемы)
- ✅ Клиент платит, не критичен бюджет
- ⚠️ **Но:** Начни с Sonnet, переходи на Opus только если не хватит

**Совет:** Opus > Sonnet только там, где Sonnet хватает. effort важнее выбора модели.

---

### ⚪🔴 Haiku 4.5 — СКОРОСТЬ

**Для:** Простые массовые задачи, быстрые ответы, низкая латентность

| Параметр | Значение |
|----------|----------|
| **Когда использовать** | Простые задачи, скорость важнее качества |
| **Сильные стороны** | Самая быстрая, самая дешёвая |
| **Слабые стороны** | Низкая точность, короткий контекст |
| **Цена** | $1 / $5 (вход / выход за 1M токенов) |
| **Самая дешёвая** | Экономия на простых задачах |
| **Context window** | 200k токенов (короче всех) |

**Используй Haiku когда:**
- ✅ Простые массовые задачи (100+ операций)
- ✅ Быстрые ответы нужны (чат, реал-тайм)
- ✅ Низкая латентность важна
- ✅ Низкая цена ошибки (можешь переделать)
- ✅ Контекст < 200k токенов

**Пример:** Batch-обработка 1000 записей — Haiku за $1, Sonnet за $3, Opus за $5.

## Выбор модели по задачам

| Задача | Модель | Effort | Примечание |
|--------|--------|--------|-----------|
| **Код: рутина** | Sonnet | Low/Medium | Стандартный разработка |
| **Код: сложный рефакторинг** | Opus | High/Xhigh | Много файлов, зависимостей |
| **Отладка бага** | Sonnet | Medium | Если сложный → Opus |
| **Документация** | Sonnet | Low | Не требует точности |
| **Аналитика** | Sonnet | Medium | Если сложно → Opus |
| **Быстрая справка** | Haiku | Low | Вопрос-ответ |
| **Batch-обработка** | Haiku | Low | 100+ однотипных задач |
| **Критичная архитектура** | Opus | Xhigh | Стоимость ошибки высока |
| **MVP/прототип** | Haiku/Sonnet | Medium | Скорость > качество |
| **Production-код** | Sonnet/Opus | High/Xhigh | Качество > скорость |

## Effort: рычаг цены

**Один переключатель: сколько токенов модель тратит на размышление. Выше уровень: глубже и дороже.**

| Уровень | Назначение | Токены | Цена | Когда |
|---------|-----------|--------|------|-------|
| **Low** | Простые массовые задачи | ↓↓ | 💰 | Batch, рутина, быстрые ответы |
| **Medium** | Сбалансированно, обычная работа | ↓ | 💰💰 | Стандартная разработка |
| **High** | Сложные задачи, обычный дефолт | → | 💰💰💰 | Архитектура, рефакторинг |
| **Xhigh** | Тяжёлая отладка, прогнозирование (Extra) | ↑ | 💰💰💰💰 | Критичные задачи, агенты |
| **Max** | Максимум без ограничений по токенам | ↑↑↑ | 💰💰💰💰💰 | Экстремальные случаи (редко) |

## Экономия: как ставить effort

**Основной переключатель на стоимость** — это effort, не модель.

```
Low Sonnet    = $0.30    (50k вход + 30k выход)
High Sonnet   = $0.60    (базовая цена за размышление)
Xhigh Sonnet  = $0.90    (больше размышления)
High Opus     = $0.75    (Opus дороже базово)
```

**Совет:** 
- На Low/Medium Sonnet: дешевле, чем Opus
- На High/Xhigh Sonnet: может быть дороже Opus, но лучше effort важнее модели
- Выбирай effort правильно, модель — вторично

## Команды Claude Code

### `/model` — Выбрать модель

Выводит 3 варианта, ставит дефолтом для новых сессий

```bash
$ /model
```

Выбираешь:
- claude-sonnet-5 (дефолт)
- claude-opus-4-8
- claude-haiku-4-5

---

### `$ claude --model <id>` — Запустить сеанс на модели

Сразу запустить сеанс на нужной модели:

```bash
$ claude --model claude-opus-4-8
```

ID модели: claude-sonnet-5, claude-opus-4-8, claude-haiku-4-5

---

### `/effort` — Выставить уровень усилий

Ползунок от Low до Max:

```bash
$ /effort
```

Или сразу:
```bash
$ /effort xhigh
```

**Совет:** по умолчанию high. Если дешево нужно → low. Если критично → xhigh.

---

### `/cost` — Показать расход сессии в токенах и деньгах

```bash
$ /cost
```

**Результат:**
```
Расчёт стоимости:
cost = вход × цена_вход + выход × цена_выход (за 1M)

Пример: 50k вход + 30k выход, sonnet-5 (3/15)
= 0.15 + 0.45 = $0.60
```

**Полезно:** перед завершением сеанса, чтобы знать сколько потратил.

---

### `/clear` — Очистить контекст перед новой задачей

Когда переходишь на новую задачу, нужно очистить старый контекст:

```bash
$ /clear
```

Удаляет предыдущую историю, начинаешь с чистого листа.

## Правило выбора

```
1. Определи сложность задачи
   ↓
2. Выбери модель:
   - Простая → Haiku
   - Стандартная → Sonnet
   - Сложная → Sonnet + High effort
   - Критичная → Opus + Xhigh effort
   ↓
3. Выставь effort под задачу (это сэкономит больше чем модель)
   ↓
4. Если Sonnet не справляется → Opus
```

---

## Примеры расчёта стоимости

### Пример 1: Простой код (Haiku, Low)

```
Входной: 5k токенов
Выходной: 10k токенов

Стоимость Haiku: $1 за 1M входа, $5 за 1M выхода
= (5k × $1 / 1M) + (10k × $5 / 1M)
= $0.005 + $0.05
= $0.055
```

---

### Пример 2: Рефакторинг (Sonnet, High)

```
Входной: 50k токенов
Выходной: 30k токенов

Стоимость Sonnet: $3 за 1M входа, $15 за 1M выхода
= (50k × $3 / 1M) + (30k × $15 / 1M)
= $0.15 + $0.45
= $0.60
```

---

### Пример 3: Критичный рефакторинг (Opus, Xhigh)

```
Входной: 100k токенов
Выходной: 50k токенов

Стоимость Opus: $5 за 1M входа, $25 за 1M выхода
= (100k × $5 / 1M) + (50k × $25 / 1M)
= $0.50 + $1.25
= $1.75
```

## Для клиентов: как рекомендовать

| Клиент | Модель | Effort | Экономия |
|--------|--------|--------|----------|
| **Стартап, бюджет tight** | Haiku/Sonnet | Low/Medium | Минимум затрат |
| **SMB, сбалансировано** | Sonnet | Medium/High | 80/20 правило |
| **Крупная компания** | Sonnet/Opus | High/Xhigh | Качество > стоимость |
| **Batch-обработка** | Haiku | Low | Максимум экономия |

---

## Ключевое правило

**Effort важнее модели.**

Sonnet с High effort может быть точнее (и дешевле), чем Opus с Low.

```
High Sonnet (High effort) > Low Opus (Low effort)
```

---

## Checklist перед выбором

- [ ] Какая сложность задачи? (простая / стандартная / сложная)
- [ ] Сколько контекста нужно? (Haiku 200k, остальные 1M)
- [ ] Скорость важна? (Haiku быстрее)
- [ ] Цена ошибки высокая? (Opus/High effort)
- [ ] Это batch? (Haiku/Low effort)
- [ ] Это production? (Sonnet/High или Opus/Xhigh)

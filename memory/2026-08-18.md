# 2026-08-18

## Сессия 1
Тема: разбор двух сайтов (theivansergeev.com, chitaemlegko.ru) как референсов для личного сайта Паши

### Сделано
- Скачал и разобрал raw HTML, robots.txt, sitemap.xml обоих сайтов (title/meta/OG/canonical/JSON-LD, цветовые токены, шрифты, аналитику, карту разделов)
- theivansergeev.com: контент-машина на ~346 страниц (гайды + топик-хабы /tema/), Person+WebSite JSON-LD, Яндекс.Метрика с вебвизором, продуманный robots.txt под ИИ-краулеров (GPTBot/ClaudeBot/PerplexityBot) + llms.txt
- chitaemlegko.ru: одностраничный лендинг под лид-магнит → Telegram, без robots.txt/sitemap.xml/canonical/schema/аналитики
- Ниша Ивана Сергеева (ИИ-агенты, Claude Code, вайбкодинг) почти совпадает с нишей Паши — прямой референс под цель «первые клиенты»

### Решения
- Модель личного сайта: за основу theivansergeev.com (контент/SEO-хаб, находимость в поиске и у ИИ-ассистентов важнее), точечно забрать понравившееся с chitaemlegko.ru
- Разобрал жалобу на частые запросы разрешений: `.claude/settings.json` уже максимально открыт (Bash(*), Read/Write/Edit(//**), defaultMode bypassPermissions) с 2026-05-06 — расширять там особо нечего. Добавил в allow недостающие типы инструментов (Glob, Grep, TodoWrite, Skill, ToolSearch). Подтверждено скриншотом Паши: переключатель режима — лейбл текущего режима внизу справа от поля ввода в панели Claude Code (не общая шестерёнка VS Code, там его нет). Режимы: Manual (стояло — спрашивает каждое изменение), Edit automatically, Plan, Auto (approve safe actions, пауза на рискованных — подходит под запрос Паши). Shift+Tab там тоже переключает (агент ошибся, сказав что не работает)
